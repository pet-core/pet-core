# Exames

O fluxo utiliza diretamente o recurso oficial de Exame.

- Tipos/catálogo: `GET /api/Exame`
- Solicitação: `POST /api/Exame`
- Detalhe: `GET /api/Exame/{id}`
- Atualização: `PUT /api/Exame/{id}/patch`
- Exclusão: `DELETE /api/Exame/{id}`

Tutores são carregados por `GET /api/Tutor` e pets por `GET /api/Pet`.
