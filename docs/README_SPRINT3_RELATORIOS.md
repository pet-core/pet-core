# Relatórios

O fluxo utiliza o recurso oficial de Relatório.

- Listagem: `GET /api/Relatorio`
- Detalhe: `GET /api/Relatorio/{id}`
- Criação: `POST /api/Relatorio`
- Atualização: `PUT /api/Relatorio/{id}/patch`
- Exclusão: `DELETE /api/Relatorio/{id}`

Tutores são carregados por `GET /api/Tutor`, pets por `GET /api/Pet` e prontuários por `GET /api/Prontuario`.
